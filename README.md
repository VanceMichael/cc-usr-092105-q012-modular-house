# 折叠箱房跨境交付

连接折叠箱房的设计、生产、装箱和海外安装资料。

## 资料范围

`contracts/domain.schema.json` 约束交换资料的基本结构，`fixtures/domain.json` 提供一组不含真实个人信息的业务样例，`docs/domain.md` 说明领域对象与必须遵守的关系。读取模块负责验证这些公开资料，并演示箱号追溯与数量守恒，不包含完整业务流程。

第二版资料把客户需求、确认配置、报价、设计与国家适配版本、钢架与水电部件来源、检测证书、生产节点、容量锁定、装箱关系、清关材料、交接记录、展开验收和多语种客户视图接在同一项目下。

当前资料确认了以下事实：

- 折叠房可收拢到标准集装箱尺寸并快速展开
- 县域已形成钢板、焊接、内装和水电预装的本地链条
- 企业通过跨境平台和海外服务站拓展五十多个国家和地区
- 协会成员企业共享同一项目资料，海外安装队扫描箱号即可追溯部件、证书与责任

## 校验方式

在仓库根目录运行 `npm test`。测试会读取样例并核对领域标识、对象清单与规则清单是否完整。
