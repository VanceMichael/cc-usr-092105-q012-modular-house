# 折叠箱房跨境交付

连接折叠箱房的设计、生产、装箱和海外安装资料。

## 资料范围

`contracts/domain.schema.json` 约束交换资料的基本结构，`fixtures/domain.json` 提供一组不含真实个人信息的业务样例，`docs/domain.md` 说明领域对象与必须遵守的关系。资料覆盖同一项目下的询盘、确认配置、国家适配版本、部件来源、检测证书、报价、生产节点、装箱关系、清关材料与展开验收。读取模块只负责验证这些公开资料，不包含完整业务流程。

当前资料确认了以下事实：

- 折叠房可收拢到标准集装箱尺寸并快速展开
- 县域已形成钢板、焊接、内装和水电预装的本地链条
- 企业通过跨境平台和海外服务站拓展五十多个国家和地区
- 阜城装配式房屋协会组织成员企业在同一项目下共同维护交付资料

## 校验方式

在仓库根目录运行 `npm test`。测试会读取样例并核对领域标识、对象清单与规则清单是否完整，并检查样例能否回答箱号追溯、保持装运数量守恒。
