# 领域约定

## 核心对象

同一项目下按交付顺序连接以下对象：

### 需求与确认

- 项目：全部交付资料的挂载点，跨成员企业共享
- 短视频询盘：跨境平台线索，仅作意向登记
- 客户需求：来自询盘或直接委托的功能与数量要求
- 确认配置：供需双方确认后的配置，是进入生产的唯一入口
- 报价：基于确认配置出具

### 设计与合规

- 设计版本：户型与结构设计
- 国家适配版本：设计版本按目的国适配形成的独立合规版本
- 部件来源：钢架与水电部件的供应记录
- 检测证书：防火、抗震等标准的检测结论

### 生产与装箱

- 生产模块：按国家适配版本投产的模块，记录生产成员企业
- 生产节点：投料、焊接、预装、装箱等关键节点
- 容量锁定：多企业之间锁定的产能数量
- 装箱单元：一箱一号，记录模块与箱号的装箱关系
- 装运批次：分批装运，每批记录箱数

### 跨境交付

- 清关材料：与装运批次对应的通关文件
- 交接记录：海运延误、服务站接管、补发、售后责任变更的追加记录
- 海外服务站：现场缺件联系人，可接管交付
- 安装验收：现场展开验收结论
- 客户视图：面向客户的多语种进度视图

## 箱号追溯

海外安装队扫描任一箱号，必须立即看到：对应户型版本、已通过的防火与抗震检测证书、生产成员企业、现场缺件联系人。这些信息来自项目共享资料，不依赖销售聊天记录。

## 已知规则

- 国家适配必须形成独立合规版本
- 短视频询盘须转为双方确认的配置后方可进入生产
- 投产后设计变化不得覆盖旧批次，已投产模块继续服从原设计
- 扫描任一箱号必须能定位户型版本、检测证书、生产企业与缺件联系人
- 多企业容量锁定与分批装运必须保持数量守恒
- 海运延误、服务站接管、补发与售后责任变更只能追加交接记录，不得改写历史
- 多语种客户视图不得展示尚未确认的承诺
- 海外伙伴只查看其负责范围

样例中的名称和编号仅用于说明字段关系，不能对应到现实中的个人、企业或业务记录。
