# 领域约定

## 目标

海外安装队扫描任一箱号，应当立刻知道：

- 箱内部件对应哪版户型
- 通过了哪些防火、抗震标准
- 由谁生产
- 现场缺件该找谁

阜城装配式房屋协会的成员企业在同一项目下共同维护以下资料，而不是散落在销售人员的聊天记录里。

## 核心对象

### 项目与需求

- **项目**：一切对象的归属。客户需求、国家适配版本、部件来源、检测证书、报价、生产节点、装箱关系、清关材料和展开验收都接在同一项目下。
- **客户需求**：短视频询盘等渠道进入的原始需求。
- **确认配置**：客户与企业双方确认的配置，是进入生产的唯一入口。
- **报价**：与确认配置绑定，配置变更则报价重出。

### 设计与合规

- **设计版本**：户型版本。投产后冻结，改款只形成新版本。
- **国家适配版本**：按目的国形成的独立合规版本，引用基础设计版本，不直接改动设计本身。
- **检测证书**：防火、抗震等检测结果，挂在国家适配版本下。

### 生产与供应

- **部件来源**：钢架、水电等部件组对应的供应商企业。
- **生产模块**：一栋折叠房的生产单元，记录生产者、设计版本与生产节点。
- **生产节点**：钢架焊接、水电预装、内装等里程碑。
- **容量锁定**：成员企业为项目锁定的产能数量，分企业记录。

### 装箱与物流

- **装箱单元**：扫描对象。箱号唯一，指向生产模块，并列出所含部件组。
- **装运批次**：分批装运，各批次箱号不重复、不遗漏。
- **清关材料**：随装运批次的清关文件。

### 交付与责任

- **交接记录**：海运延误、服务站接管、补发、售后责任变更。只追加，不改写历史。
- **安装验收**：展开验收结果。
- **客户视图**：多语种对外视图，只展示双方已确认的内容。

## 箱号追溯链

箱号 → 装箱单元 → 生产模块 → 设计版本（户型）→ 国家适配版本 → 检测证书。

生产模块给出生产者；装箱单元的部件组经部件来源给出供应商。交接记录按时间追加，最新的服务站接管或售后责任变更决定当前缺件联系人；没有任何交接时，缺件找生产者。

## 必须遵守的规则

1. 短视频询盘只有转成双方确认的配置才进入生产。
2. 国家适配必须形成独立合规版本。
3. 已投产模块继续服从原设计，设计变更不得覆盖旧批次。
4. 多企业容量锁定和分批装运保持数量守恒：各企业锁定容量合计等于投产模块数，各装运批次的箱号合计等于装箱单元总数且不重复。
5. 海运延误、服务站接管、补发和售后责任变更均追加交接记录，不改写历史。
6. 多语种客户视图不得提前展示尚未确认的承诺。
7. 海外伙伴只查看其负责范围。
8. 任一箱号必须能追溯部件对应的户型版本、检测证书、生产者与缺件联系人。

样例中的名称和编号仅用于说明字段关系，不能对应到现实中的个人、企业或业务记录。
